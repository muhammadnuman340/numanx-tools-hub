## ⚡ Quick Start: Developer Commands

If you just need to spin up the local environment or push an update, use these commands from the root directory:

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Compiles the Astro project to the `./dist/` folder |
| `npm run preview` | Serves the built `./dist/` folder locally to test production output |
