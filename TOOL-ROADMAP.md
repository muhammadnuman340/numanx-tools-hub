## SEO Template — For Every Tool

Create a standardized Astro component with these sections:

```
1. Hero section (tool name + description)
2. Interactive tool element (minimal JS)
3. Benefits section (3 premium reasons)
4. How to Use (numbered steps)
5. Features (feature grid)
6. FAQ (accordion with 3-5 questions)
7. Related Tools (RelatedTools component)
8. CTA (explore more tools)
```

### SEO Metadata Per Tool

```astro
<MainLayout
  title="SEO Title — keywords first"      // e.g. "Image Compressor - Compress JPEG PNG Online Free"
  description="Compelling meta with keyword" // max 160 chars
  keywords="comma, separated, keywords"
  faq={[
    { question: "How to use this tool?",
      answer: "Step-by-step answer with keywords..." },
    { question: "Is this tool free?",
      answer: "Yes, completely free. No sign-up needed." },
  ]}
  breadcrumbs={[
    { name: "Home", url: "/" },
    { name: "Tools", url: "/tools/" },
    { name: "Tool Name", url: "/tools/tool-name/" },
  ]}
>
```
